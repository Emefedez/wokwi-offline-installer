Offline Wokwi Environment & MCP Setup

Configure your local air-gapped Wokwi VS Code extension (auto-offline mode + MCP bridge), disable VS Code extension auto-updates, load your offline .wpk bundle, and save your valid Wokwi license key.

Instructions & Extension Auto-Update Protection

  1. Automatic Extension Protection: Running setup sets "extensions.autoUpdate": false and "extensions.autoCheckUpdates": false in your VS Code settings.json so VS Code never overwrites the offline-first Wokwi extension.
  2. Manual Check in VS Code: Open Settings (Cmd+, on macOS / Ctrl+, on Windows), search for extensions.autoUpdate, and verify it is set to None. In the Extensions panel, right-click Wokwi Simulator and ensure Auto Update is unchecked.
  3. Automatic Offline Launch: Whenever a valid offline license (user.tok) and extracted bundle.wpk are present, the extension opens directly in Wokwi Simulator (Offline) without waiting for the online iframe.
  4. Cross-Platform Executables:
    • Windows: Run WokwiOfflineSetup.exe (or install.bat)
    • macOS: Run ./wokwi-offline-setup-macos (or ./install.sh)
    • Modes: Pass --gui (Browser GUI), --tui (Interactive Terminal UI), or --cli (Flag-driven CLI).
