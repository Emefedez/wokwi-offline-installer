What Step 1 Does Automatically

  1. Installs the Patched Wokwi VS Code Extension First: Copies your chosen version (v3.7.0 or v4.1.0) into ~/.vscode/extensions/ and updates VS Code's extensions.json manifest.
  2. Disables VS Code Extension Auto-Updates: Writes "extensions.autoUpdate": false and "extensions.autoCheckUpdates": false into your VS Code settings.json (macOS, Linux, and Windows).
  3. Extracts bundle.wpk into .cache/: Unpacks the offline simulator UI & WebAssembly cores (entry.js, index.html) directly into the extension's .cache/ folder.
  4. Forces Offline Simulator Launch: Patched WokwiWebview.getHTML() immediately loads your local .cache/entry.js (using your bundle's public key) instead of connecting to wokwi.com.
  5. Cross-Platform pio Wrapper & Automatic .bin Fallback (Windows, macOS, Linux): Installs ~/.wokwi/bin/pio (and pio.cmd) + pre-built ESP32-S3 / XCasFW bootloader.bin, partitions.bin, and firmware.bin in ~/.wokwi/firmware-fallbacks/. If PlatformIO is not installed or fails to produce a .bin, Wokwi automatically provisions and boots the pre-built .bin firmware without errors!

  • Inside VS Code: Press Cmd+Shift+P (macOS) or Ctrl+Shift+P (Windows/Linux) and run Wokwi: Load and Overwrite user.tok.
  • Via CLI: Run ./install.sh --cli --load-user-tok /path/to/user.tok (or WokwiOfflineSetup.exe --cli --load-user-tok C:\path\to\user.tok).
